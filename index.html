Cómo usar la aplicación

En la demo, selecciona un nombre para editar sus datos o carga un CSV con las columnas DNI, NOMBRE, CARGO, CIUDAD, FECHA_INICIO, FECHA_FIN y PAGO. Descarga el ZIP con los documentos y el reporte CSV.

Instala Python para trabajar con XLSX, plantillas Word propias y un cruce opcional con personal. Usa etiquetas como [NOMBRE], [DNI] o {{ FECHA_INICIO }}. El ZIP local incluye un reporte Excel. La vista web muestra los datos; la maquetación final se conserva desde tu plantilla Word.

RH significa recursos humanos en esta aplicación. El contrato incluido es un modelo editable de referencia con datos ficticios; completa los datos de la empresa y adapta las cláusulas antes de usarlo. No emite recibos fiscales ni valida identidad.
